# Flightspace

Tools for reliable, specification-driven agentic engineering workflows — [flightspace.dev](https://flightspace.dev).

- **Flight** — authority plane for workstreams, claims, canon, and coordination (CLI, TUI, MCP, and Tower)
- **flight-lanes** — isolated worktree lanes landing onto a gated, fast-forward-only base
- **flight-dispatch** — delegate job dispatcher for unattended runs
- **flight-harness** — agent runtime harness, subagent wrapper, hooks, and skills

Created and maintained by **[Aeron Miles](https://github.com/aeronmiles)** (`@aeronmiles`).
